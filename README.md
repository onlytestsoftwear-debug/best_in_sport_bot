# Мини-приложение «Лучшие в спорте 2026»

Файлы: `index.html` (вся страница) и папка `assets/` (превью и ваши логотипы/фото).

## Что менять
Откройте `index.html` в текстовом редакторе и найдите блок «ДАННЫЕ» в начале скрипта:
- `CONFIG.botLink` - ссылка на бота: `https://max.ru/ИМЯ_БОТА`;
- `EVENT` - описание, дорожная карта, шаги голосования;
- `NOMINATIONS` - номинации: `logo` (путь к картинке в `assets/`), `description`, `regulation` (положение или `null`), подноминации;
- `MOMENTS` - «Лучшие из лучших моментов»;
- `DOCS` - документы НПА (`url` - ссылка на файл или страницу).
Тексты в квадратных скобках - заглушки.

## Публикация
Страница должна открываться по HTTPS. Загрузите `index.html` и `assets/` на хостинг (или на ваш сервер с nginx), затем вставьте адрес в настройках бота на платформе MAX для партнёров (раздел мини-приложения).

Кнопки «Проголосовать» открывают бота: `?start=vote` - меню номинаций, `?start=p01` - список номинантов категории.
